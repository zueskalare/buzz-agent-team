# Project record

Keep the current goals, owner decisions, task status, and links to worker reports here. The workspace agent maintains this record. The channel supervisor reads it when answering project questions.

## Working agreement

- Propose todos in their Buzz threads and link the owner’s decision.
- The workspace agent can promote accepted proposals into the selected tracker and dispatch workers for a bounded, authorized run.
- Each agent uses its own Buzz memory across joined channels. Record shared decisions here and link the source.
